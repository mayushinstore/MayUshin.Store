MAY USHINSTORE - VERSIÓN TIENDA

Esta versión incorpora el diseño de la tienda de referencia entregada por el usuario:
- encabezado con buscador
- navegación
- banner principal
- categorías circulares
- productos destacados
- beneficios
- banner promocional
- sección Nosotros
- contacto
- WhatsApp e Instagram configurados
- fotos reales del catálogo

Para GitHub Pages:
1. Subir index.html y la carpeta imagenes.
2. Settings > Pages > Deploy from a branch > main > /(root) > Save.
3. URL del sitio de proyecto: https://mayushinstore.github.io/MayUshin.Store/
